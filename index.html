w3-redw3-pinkw3-purplew3-deep-purplew3-indigow3-bluew3-light-bluew3-cyanw3-tealw3-greenw3-light-greenw3-limew3-yelloww3-amberw3-orangew3-deep-orangew3-brownw3-whitew3-light-gray / w3-light-greyw3-gray / w3-greyw3-dark-gray / w3-dark-greyw3-blackw3-pale-bluew3-pale-green
Clase semántica Uso indicado Acción
w3-dangerRojo: suele indicar una situación negativa.
w3-warningNaranja: advertencia.
w3-successVerde: resultado positivo.
w3-infoAzul: información neutral.
w3-noteAmarillo: aviso o nota.

Clase Qué define Acción
w3-dark-mode Aplica valores de variables para modo oscuro, fondo oscuro, texto claro y color-scheme: dark a una página o sección.
