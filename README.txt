# W3.CSS — REFERENCIA LOCAL

## Contenido

- `index.html` — Página de referencia con menú y tablas.
- `css/estilos.css` — Estilos visuales propios de esta página.
- `css/w3.css` — Hoja de estilos del framework W3.CSS.
- `js/app.js` — Menú lateral y buscador.
- `img/` — Carpeta reservada para imágenes locales.

## Cómo abrir

1. Abre `index.html` en el navegador.
2. El sitio puede consultarse localmente, siempre que sus recursos estén disponibles y las rutas sean correctas.

## Importante

La hoja `css/estilos.css` contiene los estilos propios de esta página de referencia. No es el framework oficial W3.CSS.

La hoja `css/w3.css` contiene el framework W3.CSS. Su inclusión puede modificar el aspecto visual de la interfaz, por lo que conviene comprobar que realmente se necesita.

## Fuente del contenido

Texto de referencia W3.CSS 6 Beta compartido en la conversación. Las descripciones se han traducido y organizado para facilitar la consulta. Comprueba la referencia original si necesitas verificar una clase concreta o si la versión beta cambia.
